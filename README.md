# app-policies

100+ iOS アプリの Privacy Policy / Support ページを GitHub Pages でホストするリポジトリ。

- 生成元スクリプト: `automation/scripts/generate-app-policy.py`
- 公開URL形式:
  - Privacy Policy: `https://sekiguchi06.github.io/app-policies/privacy-policy/{app-slug}/`
  - Support: `https://sekiguchi06.github.io/app-policies/support/{app-slug}/`

## GitHub Pages 設定
Settings > Pages > Source: Deploy from a branch > Branch: `main` / `/(root)`
